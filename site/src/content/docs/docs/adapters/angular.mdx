---
title: Angular adapter
description: Expose snapshots through a readonly Angular signal.
draft: false
---

```bash
pnpm add @gaitjs/core @gaitjs/angular @gaitjs/browser
```

```ts
import { DestroyRef, inject } from '@angular/core';
import { GaitAdapter } from '@gaitjs/angular';

readonly destroyRef = inject(DestroyRef);
readonly gait = new GaitAdapter();

constructor() {
  this.gait.start(clientGaitConfig, this.destroyRef);
}
```

`GaitAdapter` schedules browser startup after the next render, updates its readonly `snapshot` signal on flush and destroys the Core instance through the supplied destroy scope.
