# Behavioral signals, computed locally.

## A focused pipeline

gait captures browser events, aggregates them into bounded statistics and exposes versioned snapshots. Your application decides whether to display, store or send those snapshots.

## What gait does not do

- It does not send data, persist data or identify users.
- It does not decide whether a user is cheating or whether two profiles match.
- It does not expose raw keyboard content in a snapshot.
- It is a correlation signal among other application-owned signals.
